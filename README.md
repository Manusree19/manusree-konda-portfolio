# Manusree Konda — Portfolio

Responsive single-page portfolio built from the information in the supplied Profile PDF.

## Files
- `index.html` — portfolio structure/content
- `styles.css` — responsive styling and animations
- `script.js` — mobile navigation and reveal animations

## Run locally
Open `index.html` directly in a browser, or use a local static server.

Example:
```bash
python -m http.server 8000
```
Then open http://localhost:8000

## Notes
The supplied Figma URL could not be fetched in this environment, so this version uses a polished dark developer-portfolio visual direction rather than claiming pixel-perfect Figma reproduction. If a screenshot/export of the Figma frame is provided, the layout can be matched more precisely.
